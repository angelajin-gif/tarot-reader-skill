# Teacher jurisdictions

Teacher evidence is capability-scoped. Select a source by evidence fit, not by a fixed priority or citation quota. A teacher may change the working hypothesis, but never overrides Product Charter, Constitution, or Phase 4C RWS visual facts.

## Daniel — ordinary RWS upright/base bridge

Use the 78 \`daniel_card_narrative\` units for ordinary upright or unspecified cards when the reading needs the author's card-image narrative, base functional candidates, process/tension, or concrete reality bridge. For \`unspecified\`, the query returns \`upright_baseline_for_unspecified_orientation\`; it does not infer upright and it does not enter Greer's route. The unit preserves the sequence \`author visual narrative → meaning candidates → process/tension → example manifestations\`. Daniel's description is author evidence, not a replacement for the frozen visual packet; an author interpretation is not a visual fact. For an actual reversal, Daniel may be queried only as an explicitly labelled upright baseline comparison.

## Dawn — Court and rank evidence

Use the 16 Court units when Court ontology, role/person questions, or multiple-Court structure genuinely changes the reading. Use the four rank units for Page communication/learning/message entry, Knight action/progression, Queen care/influence/relationship maintenance, and King leadership/responsibility/resource governance. Use archetype, strengths, shadows, observable behavior, relationship/work manifestations, and action bridge as conditional author candidates. Do not turn rank into age, sex, appearance, identity, or proof of another person's private motive. Multiple Courts can alter the relationship structure, but Court count is not automatically person count.

## Greer — actual reversal mechanism

Query Greer only when the user explicitly supplies \`reversed\`. Seventy card entries can return card-specific \`greer_reversal_mechanism\` evidence. The eight Page/Knight entries with empty mechanism anchors instead return \`greer_general_mechanism_framework\` marked \`coverage_fallback\`, using the reviewed general-method model and pages 58–63. Its seven mechanisms are unselected candidates, not this card's reviewed reversal meaning. Select or reject a candidate only with question, position, neighboring-card, and reality evidence; if that evidence is absent, leave the reversal mechanism unresolved. Keep the upright baseline separate. A reversal is not an automatic opposite or bad outcome. \`unspecified\` never enters Greer's route.

## Nichols — Major/amplification specialist

Use the 22 Major \`nichols_major_amplification\` units only when a concrete Major motif, progression, projection warning, polarity, or archetypal amplification can change the judgment. A query requires non-empty context text and explicit \`nichols_trigger\`, \`reason_anchor\`, and \`focus_anchor\` selections. The reason anchor must be a reviewed Nichols unit field allowed for the selected trigger; the focus anchor must identify a non-empty field in that card's Nichols unit or frozen visual packet. This is an auditable route selection, not semantic validation of the prose or proof that the hypothesis is true. Missing or unsupported selections fail closed. Nichols preserves transferable method separately from author-specific amplification and deck-specific comparative material. Comparative Marseille or historical material cannot replace the RWS packet. A Major card alone is not a trigger; a no-change result need not be cited.

## Tarot Dictionary — reviewed late manifestation units

Use the existing Dictionary query only after a holistic hypothesis exists and a typed domain lookup could change it. The package contains 22 manually reviewed/queryable units out of 1,190 metadata anchors. It does not own spread organization, Court ontology, reversal mechanism, or worldview. Unsupported cards, orientations, domains, missing hypotheses, and missing reasons fail closed; no metadata anchor or raw OCR becomes a substitute.
