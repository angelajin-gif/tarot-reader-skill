## The Reader this book is trying to form

Greer 要形成的不是一位会把逆位牌换成反义词的 Reader，而是一位能在同一张牌的多种功能之间做条件诊断的人：先看牌的完整 upright range，再看什么被阻碍、延迟、内化、过量、投射、误用、回返、矫正或改向；随后用牌位、邻牌、问题、现实背景和问卜者反馈删去不合适的候选。

这位 Reader 的独特习惯是把断言改成可回答的问题，让问卜者描述图像并参与收敛；同时仍然要给出一个主判断、一个次要可能性和不能确定的部分。Greer 不试图训练一套跨牌组、跨问题、跨文化的固定逆位真理，也没有证成每一种魔法、萨满或健康隐喻的现实因果性。

## Worldview / model of Tarot

塔罗是牌图、传统、数字、元素、原型、同步性、问题、牌阵、Reader 直觉和问卜者经验之间的意义关联。牌不是脱离问题自动发射事实的装置；逆位是一种提示：某个能量可能没有如常流动，或需要换角度看见其隐藏面。正位和逆位不是两套互斥能量，而是同一功能的不同表现、极端或转向。

Greer 的现实桥接主要通过三类 frame 运作：

- **传统／预测 frame**：较愿意使用传统牌义、延迟、困难和事件倾向，但不能被翻译成确定日期、必然结果或事实证明。
- **心理／灵性 frame**：强调动机、投射、无意识、阴影、原型、成长和内在转化；这些也必须保持为可检验假设，而不是诊断。
- **对话／行动 frame**：通过问卜者的视觉描述、故事、现实例子和小行动让牌义落地；行动是选择和实验，不是牌面替用户决定。

## Sources of meaning and variable hierarchy

Greer 没有给出一个可覆盖所有场景的固定全局排序。Book Model 只能保存一个会回环的选择纪律：

1. **问题和目的**先决定需要多窄或多宽的候选空间；预测问题与心理探索不应共享同一表达强度。
2. **upright baseline**界定这张牌原本在当前问题中做什么。
3. **逆位／图像变化**产生机制候选，而不是直接给答案。
4. **牌位、邻牌、重复主题、元素质性和序列**用来增强、削弱或排除候选。
5. **现实背景和问卜者反馈**选择 ontology（人物、自己的一部分、角色、行为、事件、环境、动机、建议）。
6. **反证和未决**限制主判断的强度；没有局部证据的候选不得因为听起来有戏剧性而胜出。

这不是固定流水线。若问卜者的图像描述改变了 baseline，Reader 可以回到第 2 步；若邻牌和现实背景冲突，Reader 可以暂时保留两条路径；若没有方向信息，整个 Greer reversal branch 不启动。

## Core interpretive engine

### 机制候选与选择条件

| 候选机制 | 它改变的是什么 | 允许进入主判断的最小证据 | 常见反证／限制 |
|---|---|---|---|
| 阻碍／抗拒 | baseline 想表达但被压住 | 问题或牌位是阻力，邻牌显示交叉、抓紧、拒绝 | 有明确释放、突破或顺畅行动时降级 |
| 投射 | 自己未承认的质地被放到他人 | 用户对他人的强烈断言与牌阵内部重复的自我主题相合 | 不能用来取消对方的实际行为；没有回馈只能是候选 |
| 延迟／困难 | 功能仍在，但时机、能力或外部条件不顺 | 时间／结果位、重复逆位或现实已有等待 | 后续牌明确完成、落地或快速推进时不夸大 |
| 内在／无意识 | 能量从公共事件转入内在或未被觉察 | 心理／动机问题、隐蔽图像、内在牌位或问卜者认领 | 不能把未知动机写成对方事实 |
| 突破／改向 | 原有状态正在松动、退出或变轨 | 邻牌支持离开、解除、方向变化，或现实已有行为 | 保护、停留、资源不足会限制“已经突破”的说法 |
| 缺少／非正位 | baseline 的功能没有出现或不被允许 | 牌位要求该功能、现实确实缺少相应资源 | 不可写成道德缺陷或人格缺陷 |
| 过度／补偿 | 同一功能走向极端或在两端跳换 | 牌面、邻牌和现实都显示过量／不足的可见后果 | 没有极端证据时不凭传统负面词判断 |
| 误用／误导 | 能量存在但被用于错误目标、方法或时机 | 目标与行动不匹配，或邻牌显示策略偏移 | 不得把策略问题升级成某人恶意欺骗 |
| 回返／重新检视 | 回到前一课题、重新尝试或撤回 | 牌序、前张牌回声、现实已有复盘 | 没有回声时只保留为替代候选 |
| 矫正／药方 | 不适成为重新平衡的入口 | 牌阵明确问解决方案／动机，且能转成行动 | 不是医疗治疗、诊断或必然疗愈 |
| 非传统／萨满／幽默 | 从常规假设之外换视角 | 用户明确采用该 frame，且图像支持隐喻实验 | 这是高歧义 frame，不能用来免除证据责任 |
| 新月／黑月 | 圆形套牌的方向与月相阶段 | 只有相应圆形套牌和视觉事实 | RWS 上不可调用这一套视觉规则 |

这些是候选空间，不是从上到下的固定步骤。多机制只有在同一可观察过程上相互解释时才共存，例如“保护造成阻碍并因此延迟”；“投射、内在化和旧伤”也可以在莎拉案例中共同出现，因为有图像、牌位、问卜者语言和重复主题互相支持。若两个机制只是各自提供一个戏剧故事，则保留为 alternative，不并列塞进主答案。

### 机制怎样参与多牌 narrative

Greer 的 spread narrative 不是把每张牌的逆位释义相加。先看整体是否形成“接近—收紧—走不掉”“看不见—保护—旧伤”“问题—动机—替代—行动”等过程，再让牌位和邻牌说明过程在哪里发生。三张牌中间牌可调解两侧；多张逆位的共同主题只能成为系统信号，不能替代具体牌位和反证。原本正位的牌可成为外显资源、自然流动的部分或补救路径。

## Image → symbol → interpretation → life bridge

Greer 最强的桥不是“图像等于牌义”，而是：

1. 观察 RWS 中人物、方向、遮挡、物体、姿态、受伤、空／满、光／暗和相邻视线；
2. 把观察转成少量象征候选，例如盾牌、隐藏人物、离开、被看见、内在向导；
3. 用牌位、问题、邻牌和问卜者故事决定它是人物、角色、自我部分、行为、事件或心理状态；
4. 把主判断改写成可观察的现实过程和可选行动，并保留不能由牌确定的事实。

莎拉案例证明这条桥在 Reader 与问卜者之间共同生成：同一张权杖九在环境位可以先像外部男人，随后因莎拉的反馈和与女皇逆位的呼应，转成她自己的旧伤与防卫。变化不是“牌义被改写”，而是 ontology 和证据链发生了可追踪切换。

## Ambiguity and uncertainty

Greer 允许一张逆位同时有多个特性，但她也要求在需要清楚答案时缩小方法数量，把牌义写成开放问题，和问卜者共同删去不合适解释。Book Model 的输出格式应固定为：

- 主判断：当前证据最支持的一个机制／故事；
- 次要可能性：仍由至少一张牌或一个现实条件支持的替代；
- 未决：牌面无法选择的机制、人物动机、日期和外部事实；
- 下一步：可以观察、询问或尝试的小行动。

“任何反馈都能验证”是本书最明显的风险。若用户没有提供观察、牌阵没有相关位置、邻牌没有呼应、现实没有可检验行为，机制必须停在 candidate 或 unresolved。对于对方动机、心理诊断、出轨、疾病、法律责任、投资结果，牌不能替代事实核对与专业意见。

## Prediction, agency, and ethics

传统预测可作为一种明确标注的 frame；心理／灵性解释不能偷偷变成诊断；行动建议必须保留问卜者选择。Greer 的“矫正／药方”最安全的消费方式是把不适改写成“我可以观察什么、补哪项信息、做哪个小实验”，而不是声称牌能治疗或预告健康结果。

## Canonical case set

1. **吊人**（`ex0045`–`ex0046`）：逆境、阻塞、臣服与学习可共存，但不能把痛苦自动正向化。
2. **圣杯三逆位**（`ex0059`–`ex0060`）：邻牌隐者和酒友背景把“暂时没空”与“脱离群体／过量”区分开。
3. **女皇逆位选择例**（`ex0066`）：展示机制候选如何由问题和社会背景收敛。
4. **全大牌逆位的女士**（`ex0061`）：逆位可以否定标签化身份，不是宣判失败。
5. **全逆位／三张／解决问题／吊人牌阵**（`ex0374`–`ex0391`）：展示从整体主题到替代行动的不同 spread switches。
6. **莎拉凯尔特十字**（`ex0404`–`ex0424`）：保留“第一版过度预测”与“问卜者参与后的重读”作为同一案例的 before/after。

## Anti-patterns and self-correction

- 不把 reversed 写成 opposite、bad、failure 或固定心理诊断。
- 不把十二种方法写成逐卡流水线，也不把每个候选都塞给用户。
- 不在没有方向时调用 Greer；不把未提供的牌面方向编码为 upright 或 reversed。
- 不用 Court、传统人物词或“投射”自动锁定年龄、性别、外貌、姓名和外部人物。
- 不把多张逆位当成负面计分，不制定 Major／Court／Minor 权重。
- 不把魔法、同步性、健康隐喻当成不可反驳的现实因果。
- 在回答前检查：哪个牌面证据支持主机制？哪个邻牌／牌位反对它？还有什么不能确定？

## Unique capability conferred

Greer 真正增加的能力是：**在存在真实方向信息的前提下，把一张逆位牌的多种机制候选压缩成一个有条件、可解释、可被反证的主判断，并能把它嵌入多牌 narrative；在没有方向信息时，能明确不调用这套框架。**

这不是“逆位释义更多”。如果 Book Model 只让答案多引用“阻碍、投射、延迟”等词，却没有改变候选淘汰、主判断或不确定性，它就没有被证明有效。

## Limitations and blind spots

- 方法数量多且语言开放，存在不可证伪风险；作者给的随机关键字、极端观想和魔法 frame 需要在产品中降级为练习或显式模式。
- 部分传统人物、性别、身体和健康语言可能刻板或时代化；不能直接复制成现实识别器。
- 新月／黑月和部分牌图方法依赖特定套牌；不能移植到 RWS。
- 牌阵图、复杂版面、附录关键字和逐牌条目有视觉／译本限制；本阶段保存 route 和 provenance，但没有完成全视觉校验。
- 书中没有给出一套可量化的机制选择评分；本项目不补造固定分数。

## Internal tensions

1. 作者一方面反对固定逆位答案，另一方面逐牌条目提供大量传统和现代候选；因此 runtime 必须让逐牌 anchor 服务于候选生成，而不是候选选择。
2. 作者鼓励直觉和同步性，另一方面要求问卜者反馈、删去法和牌阵重复主题；前者扩大搜索，后者承担约束。
3. 传统预测和心理／灵性探索并存；必须在回答中标注 frame，不能把心理可能性包装成事件事实。
4. “不适即药方”能支持行动和重估，也可能掩盖真实健康风险；专业照护边界优先。
