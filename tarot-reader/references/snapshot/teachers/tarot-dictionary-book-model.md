# Tarot Dictionary Book Model

## Role

This book is a reference compiler. Its output is a bounded set of author-listed possible manifestations that can be queried after a holistic hypothesis exists. It does not own the Reader's worldview, spread organization, symbolic field, or reversal mechanism.

The governing chain is:

```text
holistic spread hypothesis
→ reason for retrieval
→ card + orientation + relevant domain lookup
→ support / refine / challenge / alternative / no change
→ return to all cards and observed reality
→ updated judgment with uncertainty
```

The dictionary can move from a symbolic structure to a plausible behavioral, relational, or event-level manifestation. It cannot turn that manifestation into a specific fact.

## What the author is teaching

The preface frames the book as a convenient reference for 78 cards in upright and reversed positions, not a set of unique standard answers. It uses the standard Waite deck as its base and explicitly describes card meaning as a broad classification system rather than a closed keyword list. The source distinguishes three possible meaning layers: card-image symbolism, related theory, and personal experience.

The author's domain headings are retrieval entrances: person, work, love, friendship, family, study, finance, extension, and psychological/spiritual prompts. The same card/orientation can therefore be expressed differently across domains. Domain does not determine which interpretation wins.

## Query discipline

1. Read the question and spread before looking up a manifestation.
2. Name the initial holistic hypothesis and why a lookup is needed.
3. Query only the applicable card/orientation/domain anchor.
4. Label the result as author-listed possible manifestation.
5. Record whether it supports, refines, challenges, or offers an alternative to the hypothesis.
6. Reject entries that conflict with stronger cross-card evidence, the spread gestalt, or observed reality.
7. Return to the whole spread and state the updated judgment.

The runtime must preserve `initial_holistic_hypothesis`, `reason_for_dictionary_retrieval`, `retrieved_entries`, `retrieval_effect`, `updated_judgment`, `rejected_entries`, and `rejection_reason`.

## Orientation and authority boundaries

```text
Daniel / general RWS → upright baseline
Greer → reversal mechanism selection
Dictionary → possible real-world manifestations
Spread → final validation
```

If orientation is unspecified, reversed anchors are unavailable. The dictionary never decides whether a reversed card expresses blockage, excess, internalization, projection, delay, or redirection. It also does not override Nichols' symbolic field or Daniel's spread organization.

## Reality levels

```text
symbolic structure
→ behavioral / relational pattern
→ plausible manifestation
→ specific fact
```

The dictionary can assist with the third level. The fourth level requires evidence-backed inference outside the entry itself and remains uncertain. Dramatic entries about separation, betrayal, illness, body, money, legal matters, or exact events are especially likely to be over-read.

## Relation to the other books

- Dawn constrains Court cards as roles, people, or multi-role structures.
- Greer selects the mechanism of a real reversal before any reversed manifestation is queried.
- Daniel organizes question, spread, reading order, and reality narrative.
- Nichols constrains symbolic amplification and projection.
- The dictionary supplies concrete reality vocabulary after those layers have already formed a hypothesis.

## Unique capability and primary failure mode

The unique capability is controlled specificity: the Reader can move from an abstract reading to a practical, domain-sensitive expression without inventing a new story. The primary failure mode is lookup capture: a vivid single entry becomes the story, the spread becomes decorative, and a possible manifestation is presented as a predicted fact.

The acceptance signature is therefore not retrieval volume. It is a changed judgment that remains spread-led, explicitly status-labeled, and able to reject the dictionary.
